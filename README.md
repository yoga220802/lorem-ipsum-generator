# Sakode MockLab

**Sakode MockLab** adalah *All-in-One Mock & Dummy Data Toolkit* modern yang dirancang untuk developer, UI/UX designer, dan QA engineer dalam menghasilkan berbagai data tiruan berkualitas tinggi untuk kebutuhan prototyping, testing API, dan perancangan antarmuka aplikasi.

---

## ✨ Fitur Utama

1. **Generator Teks Mock & Lorem Ipsum Multi-Tema**:
   - 6 Pilihan Tema: *Classic Latin Cicero*, *Nusantara Indonesia*, *Tech & Developer*, *Corporate Buzzwords*, *Bahasa Gaul & Slang*, dan *Kuliner/Foodie*.
   - Format Output: Paragraf, Kalimat, Kata, Bullets List, Ordered List, dan Struktur Dokumen HTML.
   - Export: Teks Polos, HTML, Markdown, dan JSON.
   - Live Text Statistics (Hitung kata, karakter, kalimat, dan estimasi waktu baca).
   - Filter & Highlight kata kunci pencarian.

2. **Generator Data User Indonesia (Dummy Profil & NIK)**:
   - Data realistis: Nama Indonesia (pria/wanita), NIK 16-digit, No HP (+62), Email, Pekerjaan, Perusahaan, Kota, dan Foto Avatar.
   - Tampilan Kartu Profil & Tabel Interaktif.
   - Export ke JSON dan CSV (siap untuk database seeder).

3. **Generator Placeholder Gambar UI**:
   - Provider: Placehold.co, Picsum Photos, dan Unsplash Art.
   - Preset Rasio: OG Banner (1200x630), HD 16:9, Card, Avatar, dan Mobile Screen.
   - Kustomisasi warna HEX latar, teks, dan overlay label.
   - Snippet instan untuk Direct URL, Tag `<img>` HTML, dan Markdown.

4. **Sistem Riwayat & Utilitas Global**:
   - Simpan snippet teks ke riwayat lokal (`localStorage`).
   - Global interactive Toast Notifications.
   - Pintasan keyboard `Ctrl + Enter` untuk generate ulang instan.

# or

Buka [http://localhost:3000](http://localhost:3000) pada browser Anda.

## 🛠️ Tech Stack

- **Framework**: [Next.js 16 (App Router & Turbopack)](https://nextjs.org/)
- **UI & Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: TypeScript
- **SEO**: Dynamic Metadata, OpenGraph, Twitter Cards, Semantic HTML5, Schema.org JSON-LD, Sitemap & Robots.txt.
